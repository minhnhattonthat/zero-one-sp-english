# Zero One SP — Translation glossary & style

## Style (binding)
- Faithful translation. Keep Japanese name order and honorifics: -san, -kun, -chan, -sama, -sensei, -senpai.
  Family-name + san stays (Mita-san, Kiyota-san). Bare names stay bare.
- 【...】 (decision/choice summary lines) → [...].
- 「...」 dialogue → "..." (double quotes). （...） thoughts → (...). 『...』 key terms/quotes inside a line → '...' (single quotes).
  If the JP line has no brackets (narration), add none.
- ‥‥ / …… → "..." (three dots, no spaces). Keep ！？ emphasis as !, ?, !!, ?!.
- ASCII only: no é, —, ’, “ ”, ♪, ★, Japanese characters. Use - for dashes.
- Do not insert line breaks; the build wraps text automatically (box = 2 lines x ~48 chars, longer text flows into extra boxes).
  Prefer concise phrasing: aim for <= ~95 characters per JP line where possible.
- Choice options (marked choice) must fit ONE line: <= 45 characters.
- Fragments: some JP lines are pieces of one sentence split by effects (e.g. a line that is only 「 or ends mid-sentence).
  Translate each piece so that the pieces read naturally in sequence; a lone 「 becomes " and a lone 」 becomes ".
- Sound effects in katakana (「ガチャ！」「バタン！」): English onomatopoeia in asterisks: *Clack!* *Slam!*
- Keep speech style: Kenneth/Robert foreigners (some katakana speech = accented/broken Japanese → slightly stilted English);
  Kansai dialect (アカン, ホンマ, ～や) → casual "ain't/gonna" register, no fake accents.
- Pronouns オマエ/アンタ/コイツ written in katakana = rough tone ("you", "this guy"), not names.
